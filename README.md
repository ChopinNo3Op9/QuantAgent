# QuantAgent

QuantAgent is a powerful, LLM-powered multi-agent framework designed for sophisticated quantitative research and trading signal generation. By leveraging specialized AI agents working in concert, QuantAgent simulates the collaborative dynamics of a professional quantitative research firm to evaluate assets from multiple perspectives.

## 🚀 Overview

In traditional finance, trade ideas are stress-tested by analysts with different specialties before capital is allocated. QuantAgent automates this process using Large Language Models (LLMs). The system orchestrates a graph of specialized agents—each with a distinct analytical lens—to analyze market data, company financials, news catalysts, and technical structures, culminating in a highly convicted trade proposal.

## ✨ Key Features

- **Multi-Agent Collaboration:** A network of specialized agents that analyze data in parallel and debate their findings.
  - **Fundamental Analyst:** Evaluates company financials, earnings profiles, and macroeconomic alignment.
  - **Technical Analyst:** Analyzes price action, trend regimes, and momentum scores.
  - **Sentiment Analyst:** Processes recent news, social catalysts, and overall market mood.
  - **Portfolio Coordinator:** Synthesizes the insights from all agents, resolves disagreements, and produces a final, actionable trade proposal.
- **Premium Financial Dashboard:** A sleek, dark-themed UI built for professional quants. Features include trade recommendation cards, agent transparency panels, and backtest results.
- **Backtesting & Simulation:** Visualize projected equity curves, max drawdowns, and expected returns based on the generated signals.
- **Traceable Logic:** Full transparency into each agent's reasoning, allowing users to understand exactly *why* a trade is being proposed.

## 🛠️ Architecture

QuantAgent utilizes an intelligent coordinator that dispatches context-specific prompts and data to specialized agents. The agents run concurrently, passing their structured outputs back to the Portfolio Coordinator. The Coordinator then resolves any conflicting views (e.g., strong fundamentals vs. bearish technicals) and structures a final trade thesis with calculated confidence intervals and position sizing recommendations.

## 📊 The Interface

The user interface is designed to emulate modern professional trading platforms. 
- **Sidebar Inputs:** Define the target ticker, capital amount, time horizon, and risk tolerance.
- **Overview Tab:** Displays the final trade proposal, confidence score, and high-level alignment summaries.
- **Agent Trace Tab:** A deep dive into the specific bull/bear points and momentum scores generated by individual agents.
- **Backtest Results Tab:** An interactive area chart overlaying the strategy's simulated forward performance against a benchmark, complete with Sharpe ratio and win rate metrics.
